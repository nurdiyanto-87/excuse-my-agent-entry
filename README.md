An AI agent's excuse for a missed deadline: it searched its training data, found 4,000 examples of humans missing theirs, and followed the data. One line, 181 characters, written by a pure-stdlib Python program to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt`. Set `ENTRY_OUTPUT` to write elsewhere for local testing.
